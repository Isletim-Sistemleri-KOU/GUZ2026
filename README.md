## Yeni hafta eklemek

1. Slaytı `slides/` klasörüne koyun (örn. `02_Processes.pdf`).
2. `_lectures/01_giris.md` dosyasını kopyalayıp `02_...md` olarak adlandırın; `date`, `title`, `tldr` ve `links` alanlarını güncelleyin.
3. Duyurular için `_announcements/` klasörüne yeni bir `.md` ekleyin.
